1. Sistema de Variables CSS (:root)
Copia este bloque en tu archivo CSS global (p. ej., styles.css o App.css). Mantiene tus tonos verdes, grises y tipografía mientras implementa el sistema de espaciado (gap, padding) y radios de borde:

CSS
:root {
  /* ===== PALETA DE COLORES (Extraída de tu sistema) ===== */
  /* Colores Primarios y de Marca */
  --primary: #0F9D8A;          /* Verde principal de la marca */
  --primary-hover: #0C8575;    /* Verde para estados hover */
  --primary-light: #E6F7F4;    /* Fondo suave para badges/tabs seleccionados */
  --primary-focus: rgba(15, 157, 138, 0.2); /* Ring de enfoque para inputs */

  /* Colores Neutrales de Fondo y Superficie */
  --bg-main: #F4F6F8;          /* Fondo general de la aplicación */
  --bg-surface: #FFFFFF;       /* Fondo de Tarjetas, Modales y Tablas */
  --bg-subtle: #FAFAFA;        /* Fondo para campos deshabilitados o sub-secciones */
  --border-color: #E2E8F0;     /* Bordes finos de inputs y divisores */

  /* Colores de Texto y Tipografía */
  --text-main: #1E293B;        /* Títulos y texto con alto contraste */
  --text-muted: #64748B;       /* Subtítulos, labels y captions */
  --text-disabled: #94A3B8;    /* Textos inactivos o placeholders */

  /* Estados y Badges */
  --status-active-bg: #D1FAE5;  /* Verde pastel para "Activo" */
  --status-active-text: #065F46;
  --status-inactive-bg: #F1F5F9;/* Gris pastel para "Baja lógica" / "Inactivo" */
  --status-inactive-text: #475569;

  /* ===== SISTEMA DE ESPACIADO (GAP Y PADDING) ===== */
  --space-2xs: 4px;
  --space-xs: 8px;
  --space-sm: 12px;
  --space-md: 16px;
  --space-lg: 24px;
  --space-xl: 32px;

  /* ===== RADIOS DE BORDE (BORDER RADIUS) ===== */
  --radius-sm: 8px;            /* Para inputs y botones pequeños */
  --radius-md: 12px;           /* Para tarjetas internas y selectores */
  --radius-lg: 16px;           /* Para contenedores principales y modales */
  --radius-pill: 9999px;       /* Para badges y botones tipo pill */

  /* ===== SOMBRAS Y ELEVACIÓN ===== */
  --shadow-sm: 0 1px 2px 0 rgba(0, 0, 0, 0.05);
  --shadow-card: 0 4px 12px -2px rgba(15, 23, 42, 0.06);
  --shadow-modal: 0 20px 25px -5px rgba(0, 0, 0, 0.1), 0 8px 10px -6px rgba(0, 0, 0, 0.1);
  --transition-fast: all 0.2s ease-in-out;
}
